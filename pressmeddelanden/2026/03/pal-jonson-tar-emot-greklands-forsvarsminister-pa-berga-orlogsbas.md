# Pål Jonson tar emot Greklands försvarsminister på Berga örlogsbas

**Plats**: Berga/Haninge söder om Stockholm. Med fordon kör väg 73 mot Nynäshamn/Årsta Havsbad.

**Praktisk information**: Obligatorisk föranmälan senast måndag 30/3 kl 12:30 via e-post till [amf1-ops@mil.se - öppnar din e-postklient,](mailto:amf1-ops@mil.se). Ange namn, personnummer, redaktion, kopia på presslegitimation och i vilken funktion du vill delta (reporter eller fotograf). För utländska medborgare krävs också kopia på pass vid anmälan och uppvisning av pass samt ett Request for Visit (RFV) utfärdat av Greklands ambassad vid vakten på Berga.

OBS. begränsat antal platser. Invänta bekräftelse på din anmälan och information om tider för inpassering.

Det kommer erbjudas intervjutillfälle kl 14:30 vid Berga slott.
