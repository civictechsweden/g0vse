# Parisa Liljestrand tar emot forskningsantologi från Sanningskommissionen för det samiska folket

– Jag vill rikta ett varmt tack till Sanningskommissionens ordförande Lena Nyberg och kommissionens ledamöter och sekretariat för deras arbete med denna forskningsantologi, den första delen av deras arbete som inleddes 2022. Jag ser fram emot att fördjupa mig i forskningssamlingen. Det är i kunskap om det förflutna som vi kan ta avstamp för att forma den framtid vi vill se, säger Parisa Liljestrand.
