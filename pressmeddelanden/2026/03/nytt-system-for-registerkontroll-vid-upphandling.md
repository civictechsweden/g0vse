# Nytt system för registerkontroll vid upphandling

I dag saknas ett samordnat system för leverantörskontroll vid offentliga upphandlingar och i valfrihetssystem. Upphandlande myndigheter ska genomföra nödvändiga kontroller och processen är i dag både tidskrävande och fragmenterad. Det vanligaste är därför att leverantören själv intygar att den uppfyller kraven i upphandlingen, en så kallad sanningsförsäkran. Det innebär att brott eller ekonomiska svårigheter inte alltid upptäcks. Regeringen vill nu skärpa kontrollen och sätta stopp för sanningsförsäkringar.

I lagförslaget presenteras ett nytt system där Bolagsverket ska ansvara för ett system som möjliggör samordnade registerkontroller. Med ett sådant system behöver upphandlade myndigheter och organisationer endast ha en myndighetskontakt. Leverantörskontrollerna ska kunna begäras både i samband med att en leverantör upphandlas, och vid löpande kontroll för att säkerställa att leverantören fortsatt uppfyller kraven.

– För att stärka valfriheten och värna om en sund konkurrens behöver det bli enklare att upptäcka och stänga ute oseriösa aktörer. Vårt förslag innebär att det införs ett samlat register där offentlig sektor kan söka upp tidigare domar, saldo på skattekonto, vissa skulder hos Kronofogden och annan viktig information, säger civilminister Erik Slottner.

Reglerna för att utesluta olämpliga sökanden vid användning av valfrihetssystem föreslås bli desamma som vid offentlig upphandling. Det innebär att alla upphandlande myndigheter som använder valfrihetssystem får möjlighet att utesluta sökande på i stort sett samma grunder som enligt reglerna för offentlig upphandling.

Lagändringarna föreslås träda i kraft den 1 juli 2026.
