# Ebba Busch inledningstalar vid Nordic Nuclear Forum

Ebba Busch inleder konferensen på förmiddagen med att tala om kärnkraftens roll i regionens energiomställning och det växande momentum som finns för nordiskt samarbete. Finlands miljö- och klimatminister Sari Multala inledningstalar också.

Tid för media finns. För medieförfrågningar kontakta pressekreterare Axel Vide.
