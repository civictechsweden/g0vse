# Civilministern besöker Borås för samtal om digitaliseringsfrågor

Under dagen besöker civilministern IT-koncernen Pulsen Group för dialog om AI, innovation och marknaden för svenska molntjänstföretag. Civilministern kommer även att besöka Högskolan i Borås för samtal om AI-utvecklingen. Utöver detta kommer civilministern att möta kommunföreträdare och företrädare för SPF Seniorerna för dialog om digitalisering, välfärdsutveckling samt andra frågor som berör äldre och den kommunala verksamheten.

Vid frågor och intervjuförfrågningar, kontakta civilministerns presskontakt.
