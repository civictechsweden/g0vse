# Aktivitetsstödet trappas ner

– För att fler snabbare ska gå från arbetslöshet till arbete behöver systemen utformas så att det lönar sig att arbeta. Långvarig arbetslöshet riskerar att leda till utanförskap, och därför genomför vi nu reformer som tydliggör vikten av att ta ett jobb, säger arbetsmarknadsminister Johan Britz.

Aktivitetsstöd lämnas till personer som deltar i arbetsmarknadspolitiska program och lämnas antingen med grundbelopp eller med inkomstbaserat belopp. Aktivitetsstödet med inkomstbaserat belopp trappas ner i takt med att fler ersättningsdagar används.

Regeringen fortsätter parallellt med insatser för att korta tiden i arbetslöshet och förbättra matchningen på arbetsmarknaden. Det omfattar bland annat korta, yrkesinriktade utbildningar och språkstärkande insatser som gör att fler kan ta jobben som finns. Regeringen fortsätter också arbetet med att stödja den inhemska efterfrågan genom att stärka hushållen och skapa bättre förutsättningar för företagen, till exempel genom att sänka kostnaderna för att anställa.

Tillsammans bidrar åtgärderna till att stärka arbetslinjen genom tydligare incitament att snabbt komma tillbaka till arbete.
