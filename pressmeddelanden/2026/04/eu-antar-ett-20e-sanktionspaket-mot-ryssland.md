# EU antar ett 20:e sanktionspaket mot Ryssland

– Nu har EU:s medlemsländer äntligen kunnat enas om ett 20:e sanktionspaket mot Ryssland. Sverige har under de senaste månaderna drivit på för att nya sanktioner ska komma på plats som snart som möjligt. Nu behöver arbetet med ett 21:a sanktionspaket genast ta vid, med ännu skarpare åtgärder mot den ryska energiexporten såsom ett förbud mot att tillhandahålla tjänster till alla fartyg som lämnar ryska hamnar med olja, gas eller kol, säger utrikesminister Maria Malmer Stenergard.

Genom sanktionspaketet införs fler åtgärder för att begränsa den ryska skuggflottan, bland annat transaktionsförbud som omfattar fler ryska oljehamnar samt ett raffinaderi i tredje land som deltagit i kringgående av EU:s sanktioner. Ytterligare 43 fartyg som ingår i den ryska skuggflottan förs också upp på sanktionslistan. I sanktionspaketet öppnar EU för att ett maritimt tjänsteförbud kan ersätta det oljepristak som infördes i december 2022.

Det införs även ett förbud mot att erbjuda ryska operatörer terminaltjänster för flytande naturgas (LNG) från den 1 januari 2027. Nya krav införs därtill för att säkerställa att tankerfartyg från EU inte säljs vidare till ryska aktörer eller för användning i Ryssland för att transportera olja. Förbud införs även vad gäller tillhandahållande av tjänster till ryskflaggade, ryskägda eller ryskförvaltade LNG-fartyg samt isbrytare som deltar i den ryska energiexporten.

För första gången används även EU:s så kallade anti-kringgåendeverktyg, som förbjuder export av vissa varor till ett tredje land. För att begränsa Rysslands tillgång till avancerad teknologi införs därför nya exportrestriktioner. Sanktioner riktas mot ytterligare 60 företag i Ryssland och tredje land med anledning av deras stöd till den ryska militärindustrin.

Ytterligare finansiella institutioner läggs därutöver till på listan över enheter som omfattas av transaktionsförbud, inklusive institutioner i tredje land. Genom paketet utökas också åtgärderna riktade mot sanktionskringgående via kryptotillgångar.

Sanktionspaketet innehåller dessutom åtgärder kopplade till Belarus stöd till aggressionen.
