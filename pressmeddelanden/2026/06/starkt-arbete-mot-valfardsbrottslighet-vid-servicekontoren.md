# Stärkt arbete mot välfärdsbrottslighet vid servicekontoren

– De statliga servicekontoren har en viktig roll i arbetet mot välfärdsbrottslighet. Genom att stärka samarbetet och informationsdelning mellan berörda myndigheter går det att förbättra arbetet med att förebygga fel och upptäcka risker för felaktiga utbetalningar i ett tidigt skede. Det här är ett viktigt steg som bidrar till att välfärdssystemen används på rätt sätt och att medborgarna kan lita på att deras skattemedel används ansvarsfullt, säger civilminister Erik Slottner.

Varje år sker ett stort antal besök vid de statliga servicekontoren, där SSC erbjuder statlig service för flera myndigheters räkning. I kontakten med privatpersoner och företag kan situationer uppstå där misstankar om felaktigheter väcks. Det kan exempelvis handla om omständigheter som har betydelse för rätten till ersättningar från välfärdssystemen.

Den service och vägledning som ges vid servicekontoren kan också bidra till att minska risken för oavsiktliga fel. Genom uppdraget ska SSC fortsätta utveckla sitt arbete med att informera berörda myndigheter om misstänkta felaktigheter som kan påverka rätten till utbetalningar. Arbetsförmedlingen, Försäkringskassan, Pensionsmyndigheten, Migrationsverket och Skatteverket ska stödja SSC i detta arbete.

Myndigheterna bedriver redan i dag ett gemensamt arbete för att motverka välfärdsbrottslighet. Uppdraget innebär att arbetet stärks ytterligare, bland annat genom ökad samverkan och förbättrad förståelse för vilken information som är betydelsefull för att förebygga, förhindra och upptäcka felaktiga utbetalningar.
