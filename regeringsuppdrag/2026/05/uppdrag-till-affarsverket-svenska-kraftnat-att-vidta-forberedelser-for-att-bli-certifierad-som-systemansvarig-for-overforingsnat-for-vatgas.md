# Uppdrag till Affärsverket svenska kraftnät att vidta förberedelser för att bli certifierad som systemansvarig för överföringsnät för vätgas

Regeringen ger Affärsverket svenska kraftnät (Svenska kraftnät) i uppdrag att vidta de förberedelser som krävs för att kunna bli certifierad som systemansvarig för överföringsnät för vätgas.

När den nationella genomförandelagstiftningen för direktiv (EU) 2024/1788 om gemensamma regler för de inre marknaderna för förnybar gas, naturgas och vätgas (gasmarknadsdirektivet) träder i kraft ska Svenska kraftnät också ansöka om certifiering.

Svenska kraftnät ska löpande informera Regeringskansliet (Klimat-och näringslivsdepartementet) om hur arbetet med uppdraget fortskrider.
