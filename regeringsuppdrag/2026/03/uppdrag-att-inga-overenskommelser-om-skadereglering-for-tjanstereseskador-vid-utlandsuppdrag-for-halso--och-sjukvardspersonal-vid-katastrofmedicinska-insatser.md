# Uppdrag att ingå överenskommelser om skadereglering för tjänstereseskador vid utlandsuppdrag för hälso- och sjukvårdspersonal vid katastrofmedicinska insatser

Regeringen uppdrar åt Kammarkollegiet att ingå överenskommelser om skadereglering för tjänstereseskador på motsvarande sätt som gäller för anställda vid statlig myndighet med regionerna i Stockholms, Västra Götalands, Skåne, Östergötlands, Uppsala och Västerbottens län. En sådan överenskommelse får som längst gälla till och med den 3 april 2026.

Överenskommelsen får avse hälso- och sjukvårdspersonal som genomför insatser enligt lagen om katastrofmedicin som en del av svenska insatser utomlands.
