# Uppdrag att vid de statliga servicekontoren stärka arbetet med att förebygga, förhindra och upptäcka misstänkta felaktiga utbetalningar

Regeringen ger Statens servicecenter i uppdrag att fortsätta stärka arbetet med att vid de statliga servicekontoren förebygga, förhindra och upptäcka misstänkta felaktigheter som kan leda till felaktiga utbetalningar. Statens servicecenter ska bl.a. skapa förutsättningar för att de myndigheter som Statens servicecenter har serviceavtal med informeras om misstankar om felaktigheter som kan påverka rätten till utbetalningar från välfärdssystemen.

Regeringen ger vidare Arbetsförmedlingen, Försäkringskassan, Migrationsverket, Skatteverket och Pensionsmyndigheten i uppdrag att stödja Statens servicecenter vid genomförandet av uppdraget. Det kan t.ex. handla om kompetenshöjande insatser riktade till servicehandläggare, att vid behov se över befintliga eller ta fram nya rutiner för att lämna information om misstänkta felaktiga utbetalningar till myndigheterna eller att se över eller ta fram nya rutiner för att lämna återkoppling till servicekontoren.

Statens servicecenter ska samordna uppdraget och senast den 15 januari 2027 redovisa uppdraget till Regeringskansliet, Finansdepartementet.
